# 02 · Architecturally Significant Requirements (ASR)

Нефункциональные требования, которые задают форму архитектуры. Каждое сформулировано
измеримо — чтобы его можно было проверить, а не просто продекларировать. Функциональные
фичи здесь опущены намеренно.

## Атрибуты качества

### ASR-1 · Устойчивость к перезагрузке
Запущенная задача не теряется, если страницу перезагрузили или вкладка упала. После
рестарта платформа находит активные задачи и продолжает их.
Проверка: пользователь запустил генерацию, через 10 секунд обновил вкладку — задача
продолжается, результат в итоге приходит. Мера: из хранилища восстанавливаются все
активные задачи.

### ASR-2 · Гарантированное завершение
Каждая задача обязана прийти в терминальное состояние; «вечных спиннеров» быть не должно.
Проверка: бэкенд перестал отвечать — задача уходит в `timeout` с понятным исходом
(повтор или ошибка), а не исчезает молча. Мера: задач без терминального состояния — ноль.

### ASR-3 · Дешёвое добавление нового типа задачи
Новый тип задачи подключается конфигом, без копирования стейт-машины.
Проверка: добавить «AI-маршрут дня» — это конфиг плюс контракт ответа. Мера: нового кода
на тип порядка 60 строк, стейт-машина не дублируется.

### ASR-4 · Единый транспортный контракт
Long-poll и WebSocket работают через один и тот же job-контракт; смена транспорта не
трогает доменную логику задачи.
Проверка: перевод генерации блоков с опроса на ws-push меняет только выбор адаптера.

### ASR-5 · Корректность повторов
Ретраи и повторный запуск не создают второй результат — идемпотентность по `job-id`.
Мера: при любом числе повторов одной задачи в системе ровно один результат.

### ASR-6 · Наблюдаемость
Переходы состояний и исходы задач логируются одинаково, независимо от типа задачи и
транспорта.

### ASR-7 · Эволюционируемость
Хранилище состояния спрятано за портом, чтобы позже заменить его серверным без
переписывания потребителей.

## Ограничения

- Стек — Effector, Farfetched, Runtypes, как в целевом модуле.
- Единственное персистентное хранилище на клиенте — localStorage.
